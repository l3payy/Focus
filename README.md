# Focus — ужасное внимание к деталям лишь для того, чтобы их не замечать

Стандартный Chrome предлагает четыре способа сохранить нужный сайт — и все они далеки от идеала:

- **Стартовая страница:** перегружена мусором, вмещает мало ссылок и медленная.
- **Панель закладок:** отъедает полезную высоту экрана и мозолит глаза на каждом открытом сайте.
- **Список для чтения:** спрятан глубоко в меню, из-за чего о нем легко забыть.
- **Группы вкладок:** перегружают браузер, а при сохранении тихо превращаются в обычные закладки.

Когда вы работаете над несколькими проектами и хотите временно отложить 20 рабочих вкладок, нет ничего более рабочего чем закрыть их и потом пытаться откопать в истории.

**Фокус создан для решения этой проблемы.**
Это чистое и сфокусированное пространство новой вкладки, которое избавляет от цифрового хаоса.

## Три пространства для разных задач

<br>

### ☁️ Облачка
*Интерактивная доска для идей, заметки и визуальный контекст.*

Фоновая сетка и поисковая строка — всё остальное пространство принадлежит вам.

- **Мгновенная вставка:** перетаскивайте картинки или вставляйте их прямо из буфера через `Ctrl+V` — скачивать файлы ради короткой заметки больше не нужно.
- **Визуальные закладки:** любая картинка может стать ссылкой. Например, клик по картинке открывает YouTube.
- **Свободное творчество:** оставляйте быстрые наброски и заметки встроенным карандашом и текстом.
- **Локальное хранение:** все элементы и медиафайлы хранятся исключительно на вашем устройстве.

### 🎯 Фокус
*Минималистичный стартовый экран для самого важного.*

Лаконичный интерфейс без отвлекающих деталей, созданный для ежедневных сервисов.

- **Строгий лимит:** максимум 16 плиток — только те сайты, которые действительно нужны каждый день.
- **Быстрое добавление:** сохраняйте ссылки через контекстное меню (ПКМ) или клавиши `Ctrl+V`.
- **Офлайн-доступ:** иконки запекаются в локальный кэш при первом добавлении и всегда доступны без сети.

### 🚀 Фокус+
*Вместительное пространство для рабочих процессов.*

Удобное хранилище для ресурсов, к которым нужен быстрый доступ во время работы, без захламления личного экрана.

- **Сетка на 72 сайта:** компактные плитки с наглядными названиями.
- **Разделение контекстов:** помогает не мешать рабочие вкладки с личными на одном компьютере.
- **В будущем:** если вам нужны вложенные папки (до ~600 ссылок) — напишите об этом в Issues, я пока не уверен.
