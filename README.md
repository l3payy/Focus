## Зачем

Стартовая страница Chrome — либо бесполезная, либо перегруженная. Сторонние New Tab из маркета — как правило, заброшенные с 2015 года и не решающие главную проблему.

Chrome предлагает хранить сайты четырьмя способами, и все неудобные:

- стартовая страница — два поисковика и мусор;
- панель закладок — отъедает место у сайтов;
- список для чтения — попробуй его ещё найди;
- группы вкладок — сохраняются непонятно куда.

Когда работаешь с проектами и нужно на день отложить 20 вкладок с Are.na или референсов интерфейсов — сохранить их некуда, не захламляя браузер. Остаётся закрывать всё и потом искать в истории.

Поэтому я сделал Фокус. Чтобы не страдать от этого.

## Три пространства

### ☁️ Облачка

Фон-сетка и поисковик. Остальное — твоё.

- Картинки — перетаскиванием или `Ctrl+V`, качать и хранить маленькие заметки больше не нужно
- Каждая картинка может быть ссылкой: YouTube у тебя открывает не иконка YouTube, а кадр из клипа Ланы Дель Рей. Удивительно!
- Заметки и рисование карандашом для идей
- Всё хранится локально

## Почему Фокус, а не любое другое

**1. Иконки — отдельная база `sites-db.js` с настройками иконок для каждого сайта:

```js
var SITES_DB = {
  'twitch.tv':  { bg: '#FFFFFF', icon: 38, fit: 'long', name: 'Twitch' },
  'github.com': { bg: '#FFFFFF', icon: 38, fit: 'long', name: 'GitHub' },
  'kick.com':   { bg: '#000000', icon: 42 },
};
```

Иконки грузятся с DuckDuckGo (`ip3` — потому что origin и s2 Google часто отдают битые), кешируются, затем расширение подбирает им фон и размер. Пока у других значок YouTube растянут и мыльный — здесь он как иконка на телефоне. База заполняется вручную, это незаметная работа, но делает восприятие на порядок лучше.

**2. Никакого мигания.** Новая вкладка обычно мерцает при открытии — так браузер работает с данными. Здесь часть элементов «запекается» заранее: последнее пространство, тема и скелетоны рисуются синхронно, фоны и иконки отдаются с диска через service worker. Сеть дёргает сервер иконок один раз — при добавлении.

- Ноль фреймворков, ноль запросов при открытии — Vanilla JS
- `IndexedDB + Cache Storage + localStorage`, `Chrome MV3, chrome_url_overrides`
- Свой поисковик и видимость поиска — отдельно для каждого пространства
- Несколько тем, темные, белые, цветные и весёлые

## Статус

> Фокус сейчас в альфе, но функционально готов. Пользуюсь каждый день локально.

Осталось отполировать вид: он сейчас грязноват — укоротить разделители, поправить скругления, добавить больше тем. Основную функцию выполняет, поэтому в стор пока не публикую.

Сейчас доступен на GitHub — обновлять придётся руками, меняю почти каждый день: выкидываю лишнее, упрощаю, ускоряю.

**➡️ https://github.com/l3payy/Focus**

```bash
1. chrome://extensions → Режим разработчика
2. Загрузить распакованное расширение → папка Focus/
3. Открыть новую вкладку
```
